# QRFolder 能做什么

> 这份文档写给**不写代码的人**看：客户、老板、要拿它去谈事的人。
> 它讲清楚这个东西是什么、能干什么、你需要在后台点哪些地方。
> 想知道怎么装、怎么运维，看 [deployment.zh-CN.md](deployment.zh-CN.md)；
> 想知道安全上防住了什么，看 [security.zh-CN.md](security.zh-CN.md)。

---

## 一句话

**把服务器上的一个文件夹，变成一个可以扫码打开的资料网站。**

网站上的内容就是你文件夹里的内容。你在文件夹里放什么，客户就能看到什么；你删掉，网站上也就没了。不需要二次上传，不需要生成静态页面。

---

## 它解决什么问题

假设你有一批产品资料 —— 说明书、图纸、报价单、样册 —— 放在服务器上，要发给客户。

常见的几种做法各有各的难受：

| 做法 | 麻烦在哪 |
|---|---|
| 微信/邮件直接发文件 | 文件大了发不动；更新一版就要重发一次；客户手上是哪一版说不清 |
| 网盘分享链接 | 链接里带着网盘品牌；有广告、有"打开 App"；链接随时可能失效；客户得先注册 |
| 让技术同事配 nginx 目录 | 默认页面很丑、不能改；加个密码要改配置文件重启；没有后台 |
| 自己写一个 | 文件名乱码、大文件下载断、中文名、路径安全……坑很多，做出来还不好看 |

**QRFolder 的做法是**：你把资料按客户/项目分好文件夹，每个文件夹生成一张二维码，印在样册、名片、包装或展台上。客户扫一下就直接看到资料列表，点开就能看或下载。改资料不用重新印二维码 —— 二维码编的是文件夹地址，地址不变，内容随便换。

---

## 访客（你的客户）看到什么

打开网址或扫码之后：

- **一个文件列表** —— 文件名、大小、修改时间，可以按这三列排序，右上角有筛选框，打字就能过滤
- **点文件直接看** —— PDF、图片、视频、音频、文本可以直接在浏览器里打开，不用先下载
- **不想看就直接下载** —— 中文文件名不会变成乱码，也不会变成一串 `download`
- **大文件也没问题** —— PDF 能跳到第 50 页，视频能拖进度条，不用等它整个下完
- **手机上也能用** —— 窄屏自动收起次要的列，按钮排布跟着变
- **中英文切换** —— 页面右上角一个按钮
- **明亮 / 黑暗** —— 默认跟随访客手机或电脑的设置，访客也可以自己点按钮切换，选择会被记住
- **进入子文件夹** —— 顶部有面包屑，随时能回上一层

有一件事它**故意不做**：打开网站首页时，**不会列出你有哪些文件夹**，只显示一段你可以自己写的欢迎语。因为首页地址最容易被人猜到，如果首页把所有客户名都列出来，等于把客户名单公开了。客户必须扫到对应的二维码，才能进到那个文件夹。

## 你在后台能做什么

后台地址通常是 `你的域名/admin`，用**用户名 + 密码**登录（第一次打开会让你建一个管理员账号）。

### 概览

一眼看到服务在不在跑、监听了哪个端口、有多少个目录、最近的访问记录，还有你自己是谁、被授了什么权限。几个运维快捷操作（重载配置、清空日志、换一把会话密钥）只有超级管理员看得见。

### 目录管理 —— 这里是日常用得最多的地方

| 能做的事 | 说明 |
|---|---|
| 新增目录 | 选一个父目录 + 填一个目录名就行。**文件夹不存在的话服务器会替你建出来**；网址里那个前缀不填就跟目录名一样 |
| 改、删 | 改名会让网址跟着变。删除在**编辑弹窗底部的「危险操作」区**，分两种：**取消发布**（只是不再对外，服务器上的文件夹和文件原样保留）和**删除内容**（连文件夹一起删，不可撤销） |
| 删除内容 | 只有超级管理员能做，而且要在弹窗里**手打一遍目录名**才执行。磁盘根目录、程序目录、以及「允许的父级目录」本身一律拒绝 |
| 扫描导入 | 列出某个父目录下**已经存在**的文件夹，勾选哪些要发布，一次导进来 |
| 浏览 | 点「浏览」能看到选中的父目录下已经有哪些文件夹，点一下就把名字填进去 |
| 单独设密码 | 某个目录可以只要密码才能看，比如只给某个客户的资料 |
| 单独设标题 | 列表页顶部显示的文字，不填就用目录名 |
| 单独设 IP 白名单 | 只允许特定来源访问这个目录 |
| **生成二维码** | 一键生成这个目录的访问二维码，可以下载 **SVG**（打印用，放多大都不糊）或 **PNG** |
| 单独设排序方式 | 这个目录默认按什么排 |

### 管理员 —— 需要多人分工时才用

**超级管理员**是这套系统的"老板账号"，有且只有一个，什么都看得到、什么都能改。

**子管理员**是你自己建出来的账号。建的时候一个一个人来配：

| 配什么 | 说明 |
|---|---|
| 用户名 | 登录用的名字，不区分大小写 |
| 功能权限 | 13 项，**逐项勾选**。没勾的连入口都不显示，直接输网址也是 404。有几项会自动带上「查看目录列表」这类前置项 —— 一个"改完就看不到结果"的功能，点下去只会报错 |
| 能用的服务器目录 | 从「系统设置 → 允许的父级目录」里勾几个给他。他建目录时只能在这些位置里选，也不能把目录指向别人名下的目录 |
| 名下目录 | 他建出来的目录自动归他；你也可以把已有目录改派给他 |

**勾给他的父目录如果服务器上还没有，保存时会自动建出来**（系统设置里往池子里加路径也一样）。建不出来 —— 上一级不存在、没权限、或者写成了相对路径 —— 就会拦住这次保存并说明原因。这样不会出现"账号里授权了、磁盘上却没有"的状态：那种事只有等他真的去用的时候才会暴露。

**「允许的父级目录」是硬边界**，池子外面的文件夹不能直接发布，超级管理员也不例外。唯一的例外是**路径没改动**的老目录：池子收紧之前安排的位置，改标题、改排序都还能用，但不能改到池子外面去。

**容器本身不发布。** 一个位置要么是「放东西的容器」（池子里的路径、子管理员的工作区），要么是「一个对外发布的内容目录」，不能兼着 —— 这类文件夹不会出现在扫描候选里，直接提交也会被拒。**它下面的子文件夹不受影响**，那才是常规用法。

子管理员**只能看到自己名下的目录**：目录列表里没有别人的，文件管理选不到别人的，访问日志里也只有自己那些目录的记录，连在浏览器里直接敲别人目录的网址都是 404（而不是"需要密码"——那等于告诉了他这个目录存在）。

**下面这些不给子管理员，不是勾选项，是写死的：**

- 管理员账号管理（否则他能自己给自己提权）
- 访问控制（整站密码、IP 白名单、登录限流 —— 每一项都能把我们自己锁在门外）
- 配置导入导出（导出里有全部密码哈希和会话密钥）
- 系统设置里的全局项（端口、后台路径、反向代理、上传总开关、日志、扫描父目录）
- 域名与证书、重载配置、换会话密钥

**权限改了立刻生效，不用重新登录。** 撤掉一项权限、停用账号、删掉账号，他下一次点页面就生效。

**一个目录只能归一个人**，不支持多人共管。**超级管理员也只有一个**；万一密码丢了，在服务器本机上打开后台，会重新出现首次设置页。

### 文件管理

选一个目录进去，可以看到里面的文件和子文件夹，也可以**上传**文件（拖进去，或者点选，支持一次选多个、支持上传到子文件夹）。

如果你不希望这个服务有任何写入能力，可以在"系统设置"里把上传整个关掉 —— 关掉之后它就是一个纯只读的文件站，文件管理页仍然可以浏览和下载。

### 外观设置

见下面"能改到什么程度"。

### 访问控制

| 能做的事 | 说明 |
|---|---|
| 整站密码 | 打开整个网站都要先输密码 |
| 超级管理员密码 | 改你自己的后台登录密码（子管理员的密码在「管理员」页改） |
| 后台 IP 白名单 | 只允许特定 IP 打开后台，比如只允许公司网络 |
| 登录限流 | 密码输错几次就锁一段时间，逐次加倍，防爆破 |
| 登录有效期 | 后台登录多久需要重新登录（默认 12 小时） |
| 会话绑定 IP | 打开后，登录凭证被复制到别的网络也用不了 —— 更安全，但手机切换基站会掉线，移动办公建议关掉 |
| 敏感文件规则 | 哪些扩展名、哪些文件名一律不许访问（默认已经屏蔽 42 种扩展名和 10 类文件名，见下） |

### 系统设置

| 能做的事 | 说明 |
|---|---|
| 监听地址和端口 | 改完需要重启服务（页面会提示） |
| 对外访问地址 | **二维码里编的地址**，填你的域名或"IP + 端口" |
| 后台路径 | 默认 `/admin`，可以改成一个难猜的，减少扫描器噪音 |
| 反向代理信任 | 只有在确实用了反向代理（如 Caddy/nginx）时才开 |
| 文件上传 | 是否允许上传、单个文件上限多大、允不允许覆盖同名文件 |
| 日志 | 是否记录、记多少条、是否落盘、是否给 IP 打码、日志级别 |
| 允许的父级目录 | **整个站点的目录边界**：浏览、扫描、新建目录都只能在这个范围内。加进来的路径如果服务器上还没有，保存时会替你建出来 |
| 配置导入导出 | 把当前配置下载成一份 JSON，或者粘贴一份 JSON 导进来 |

### 域名与证书

填上域名和邮箱，点"保存并应用"，剩下的交给服务器上的 Caddy：

- 自动申请 HTTPS 证书（Let's Encrypt，免费）
- 到期前自动续签，不用你管
- 自动把 http 访问跳到 https

页面上会显示**当前实际正在用的那张证书**：谁签发的、什么时候到期、还剩多少天。它不显示"我申请过"，而是真的去握手一次、把证书读出来看 —— 因为"申请过"和"正在用"是两回事。

> 调试时建议先打开"测试环境"，等确认没问题再换正式环境。正式环境有频率限制（同一个域名每周 5 张），反复试错会把配额用完，一等就是一周。

### 访问日志

最近 500 条访问记录（条数可调），能按状态码和路径过滤，能导出成 CSV。日志里能看到：什么时候、哪个 IP、访问了哪个路径、返回什么状态码、用了多久、什么浏览器。

**没登录任何人打不开后台**，日志也不例外。子管理员只看得到自己名下目录的记录 —— 连"还有几条你看不到的"都不显示。

## 能改到什么程度

这一节是给"想把界面改得看不出是现成产品"的人看的。**下面每一项都在后台里改，不用碰代码、不用重启。**

### 品牌与抬头

| 改什么 | 效果 |
|---|---|
| 产品名称 | 后台抬头、浏览器标题、登录页统一改名 —— 改一处，全站跟着变 |

### 主界面（扫码进来的第一页）

| 改什么 | 效果 |
|---|---|
| 标题 | **中英文各填一份**，按访客的语言显示 |
| 正文 | 同上，中英文各一份 |
| 图片 | 站内路径（如 `/logo.png`）或外部链接都行；外链的域名会被自动加进该页的安全策略里，不会被自己拦掉 |
| 图片说明文字 | 中英文各一份（图片加载失败时显示的文字，也供读屏软件用） |
| 图片宽度 | 按像素指定，或留 0 表示自适应 |
| 底部提示语 | 中英文各一份，比如"如有问题，请联系二维码提供方。" |
| 页脚文字 | 想加版权信息就加，默认不放任何页脚 |
| 首页行为 | 显示欢迎页，或者干脆返回 404 |

**中英文两份互不干扰**：只填了中文，英文访客看到的仍然是通顺的英文默认文案，不会冒出一句中文。

### 目录列表页

| 改什么 | 效果 |
|---|---|
| 站点标题 | 浏览器标签页上的后缀，也是主界面标题的回退值 |
| 主题色 | 链接、按钮、高亮的颜色 |
| 文件夹颜色 | 列表里文件夹图标的颜色 |
| 明暗模式 | 跟随系统 / 强制明亮 / 强制黑暗 |
| 密度 | 舒适 / 紧凑（每行的高度） |
| 显示哪些列 | 面包屑、文件大小、修改时间、筛选框、统计行 —— 逐项开关 |
| 默认排序 | 按名称（文件夹优先）/ 名称 / 大小 / 时间，升序或降序 |
| 时区 | 显示文件时间用哪个时区（可跟随访客设备） |
| 语言 | 跟随浏览器 / 固定中文 / 固定英文 |
| 预览扩展名 | 哪些类型的文件点开直接在浏览器里看（默认 23 种） |
| 强制下载的扩展名 | 哪些类型一律下载、不在浏览器里打开（默认 14 种，主要是 HTML/SVG/JS 这类**能执行脚本**的类型） |
| 自定义 CSS | 想微调样式就直接写 CSS 追加进去 |

**外观设置页自带实时预览** —— 落地页和目录页各一个 iframe，改完保存立刻能看到效果，不用切到前台。

### 安全相关的

上面"访问控制"和"系统设置"两张表里的每一项都在后台可改，包括那些平时不建议动的参数（登录限流的具体次数和时长、并发哈希上限、可信代理网段等）。**没有藏在配置文件里、必须手改 JSON 才能调的开关。**

## 安全方面（大白话）

这东西是放在公网上的，安全上做了这些：

- **别人没法通过网址翻到你的别的文件。** 各种"绕过路径限制"的手法（`../`、编码过的斜杠、Windows 的保留文件名、符号链接等）都被挡住了，而且**项目源码和配置文件永远不在可访问范围内** —— 就算你把内容目录配错了，校验器也会拒绝启动并告诉你哪里不对。
- **密码不会明文存。** 存的是 scrypt 哈希（一种故意算得很慢的算法），拿到文件也反推不出密码。
- **登录有防爆破。** 同一个 IP 连续输错会逐次加倍锁定；同时限制并发，防止有人用大量并发登录把服务器内存打爆。
- **后台页面不能被别的网站套进 iframe** 骗你点击。
- **子管理员翻不到别人的目录。** 不是"界面上不显示"，是真的打不开：目录列表、文件管理、访问日志、二维码都按归属过滤，直接敲别人目录的网址得到的是一个普通的 404（连"这个目录存在"都不告诉他）。权限是每次点页面现查的，撤了立刻生效。
- **资料目录里的 HTML / SVG 文件不会被当成网页执行。** 这条很重要：如果客户能往你服务器上传一个 HTML，而它又能在你的域名下执行脚本，那它就能偷后台的登录凭证。所以这类文件一律强制下载。
- **页面上没有任何第三方痕迹。** 没有 CDN、没有分析统计、没有外部字体、没有第三方 JS。响应头里也不会暴露"用的是什么服务器软件"。
- **搜索引擎收录不到。** 有 `robots.txt` 和 `noindex` 标记（但这只是"请勿收录"的礼貌请求，不是防护 —— 真正的防护是别人猜不到你的目录地址）。

想深入了解，看 [security.zh-CN.md](security.zh-CN.md)。

## 你需要准备什么

**服务器**：Windows 或 Linux 都行，装 Node.js 22.18 或更高版本。

**不需要装的东西**：不需要 npm install 任何依赖，不需要数据库，不需要 Docker，不需要构建步骤。整个程序就是一堆源码文件，复制过去就能跑。

**一份目录规划**：想清楚资料怎么分文件夹。建议一个客户/一个项目一个文件夹，因为二维码是按文件夹生成的。

**域名（可选但推荐）**：想要 `https://` 和好记的地址就需要。不配域名也能用，直接用 `IP:端口` 访问。

**HTTPS 证书（可选）**：配了域名后由 Caddy 自动申请，免费。

## 常见问题

**二维码印出去了，以后改资料要重新印吗？**
不用。二维码编的是文件夹地址，不是某个文件。地址不变，你在文件夹里怎么增删改都行。

**我能只让某个客户看到他的资料吗？**
能。给那个目录单独设密码，密码只在二维码旁边或者电话里告诉他。

**首页会不会把我所有客户的名字列出来？**
不会。首页只显示你写的欢迎语，不列任何目录。客户必须扫到对应的二维码才能进到自己的文件夹。

**能不能不让别人下载，只能在线看？**
不能强制。任何能在浏览器里看到的内容，技术上都能被保存下来。可以对特定类型设置"直接在浏览器里打开"，但拦不住有心保存的人。

**客户说打不开，怎么办？**
先让他在浏览器里直接输网址（绕开扫码）。如果他自己输能打开、扫码打不开，那是二维码印小了或者被裁掉了白边 —— 二维码四周必须留白。如果都打不开，检查服务器和证书。

**能不能换成我自己的品牌？**
能。产品名一改，后台抬头、浏览器标题、登录页全跟着变；主界面的标题正文也都能改。页面上没有第三方的 logo 或版权信息。

**资料很多、目录很大，会不会很慢？**
列表一次最多显示 5000 条（超过会提示），扫描是并发的。正常的资料目录（几百上千个文件）没有压力。
