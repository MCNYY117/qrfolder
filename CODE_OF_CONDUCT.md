# Code of Conduct

## The short version

Be decent to people. This is a small project maintained in someone's spare time,
and the bar is simply: don't make it unpleasant to be here.

## What that means in practice

- **Critique the code, not the person.** "This breaks type stripping" is useful.
  "You clearly don't understand TypeScript" is not, and it is the fastest way to
  get a thread locked.
- **Assume good faith.** The person you are replying to may be translating from
  another language, may be on a different platform, and may have read the docs
  more carefully than you did.
- **Take "no" for an answer.** A declined patch is not an invitation to
  relitigate it in three more threads. The two hard rules in `CONTRIBUTING.md` —
  no runtime dependencies, the code must survive type stripping — are not open
  for negotiation, however good the argument for an exception is.
- **English is the working language of the tracker**, but imperfect English is
  never a reason to dismiss a report. Clarity beats grammar, and a bug report
  written in halting English is still a bug report.

Unacceptable behaviour includes harassment, insults, discriminatory or
sexualised language or attention, deliberate intimidation, publishing someone's
private information, and sustained disruption of discussions.

## Scope

Issues, pull requests, commit messages, code comments, and anywhere you are
representing the project.

## Reporting

If someone is behaving badly, use GitHub's built-in reporting on the comment or
the profile (**Report content**). GitHub handles account-level action, and it
keeps the report out of the thread, which is usually what the person reporting
wants.

If you would rather not go through GitHub, open an issue that says only that you
need a maintainer to contact you — nothing else — and one will.

Reports are handled privately. A reporter will not be named without their
agreement.

## Enforcement

Depending on severity: a private word, a warning, editing or deleting a comment,
a temporary restriction from the tracker, or a permanent ban. Continuing after a
warning is the fastest route to the last of those.
